## Boundary decision surfaced by the review

The ancestor guard is scoped to the read's **scope base**: the project root for
project-scope reads, the user config directory for user-scope reads, and
`~/.pfl` for store reads. A symlink **at** the scope base is treated as prefix
resolution (a dotfile-managed `~/.claude` stays usable); a symlink **below** it
is traversal and is refused. This keeps the hostile project case
(`.claude -> /outside`) closed without breaking a symlinked user config
directory. Recorded in ADR 0002 §1.
