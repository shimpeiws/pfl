# Security reviews

One record per review, named `YYYY-MM-DD-<short-subject>.md`. A record states
the diff reviewed, the invariants checked, the findings, and the disposition of
each finding. The policy that requires these records is
[`../review-policy.md`](../review-policy.md).

Review records are added as trust-boundary pull requests are merged; none are
present yet because M6 Phase 0 adds no trust-boundary change.
