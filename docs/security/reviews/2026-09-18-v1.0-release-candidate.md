## Accepted risk A3 — re-evaluated and reaffirmed

A3's reopening condition ("M8 lands") is met. M8 narrowed the approximation — a
linked worktree now resolves the same root with or without a grant — but a
command run from a **subdirectory** still needs the gated ancestor walk to find
the repository root, so the runtime cannot be determined before the project id.
The residual grants attribution, not a boundary crossing: every enabled path is
already authorized by an explicit grant, and only `remote.*.url` is read.
`docs/security/accepted-risks.md` A3 now carries the corrected reopening
condition (a read command gains `--runtime`, or the root index records the
runtime/ancestor roots) and names all three callers.
