## Release-candidate exercise (stage 1)

The `v1.0.0-rc.1` tag was pushed on 2026-09-18 and ran the full release
workflow. Every step up to and including the dry-run publish passed — the
gate (`check`, `format`, `build`, `typecheck:test`, `test`, `knip`), the
tag/version check, the tarball inspection (including the map-free assertion),
the packed-tarball smoke test, and `npm publish --dry-run --tag next`. The real
`Publish` step was correctly skipped. The first run failed at the publish step
(R9) and the fix was verified by re-running the tag; no npm publish occurred at
any point.
